# 功能擴充構想（2026-07-22 live 驗證時觀察到，供下一輪升級參考）

以下是實際操作 Wayground 介面時看到、但本輪 skill 尚未涵蓋的功能。依「提升 agent 與平台操作吻合度」排序。

## 高價值

1. **個別化調整 / 差異化支援**（「分配」按鈕的真正用途，本輪誤以為跟指派有關）
   實際是無障礙/差異化設定：額外做題時間、參與者嘗試次數、大聲朗讀、延長截止日期、提示、避免回答問題、減少答案選擇、語音轉文本、閱讀障礙字體、翻譯、字體大小、雙語字典。
   → 可加 `scripts/pw/set-accommodations.mjs`，讓老師針對特教/資源班學生一次設定支援。這是 Wayground 主打的差異化教學賣點，目前完全沒碰。

2. **遊戲模式擴充**（assign.mjs 目前固定用「經典」）
   完整選項：經典/佔領高峰(題數≥10才開放)/操場/測驗模式/團隊模式。
   → `assign.mjs` 加 `--game-mode` 參數，題數足夠時可選佔領高峰（適合複習關卡制）或團隊模式（適合分組競賽）。

3. **選擇班級**（作業詳情頁的「選擇班級」，本輪跳過未選）
   → `assign.mjs` 加 `--class-name` 參數，直接指派給特定班級而非「未分配」。

## 中價值

4. **AI 生成路徑**（建立畫面的「用人工智慧生成」卡片）——貼主題/網站/YouTube/文字內容，Wayground AI 直接出題。
   → 可做 `scripts/pw/generate-ai-quiz.mjs` 作為 build-xlsx.mjs 的替代路徑，適合老師沒有現成題庫、只有教材文件的情境。

5. **封面圖片**（發布 metadata 對話框的「添加封面圖片」，本輪略過）
   → `publish.mjs` 加 `--cover-image <path>` 選項。

6. **教學目標標籤**（發布對話框：教/複習/練習/其他）
   → `publish.mjs` 加 `--goal` 參數，影響測驗在資源庫的分類曝光。

7. **反作弊監控 / 嚴肅主題**（會話設定畫面看到「新的」標籤功能，未展開細節）
   → 下一輪值得展開看內容，可能對正式考試情境有用。

## 低價值／備查

8. **從頭開始創建**（手動逐題建立，而非匯入）——不太適合自動化場景，除非要做「單題快速新增」的輕量工具。
9. **Google 雲端表單匯入**、**貼上問題**分頁——匯入來源的其他選項，若老師題目來源是 Google Form 可考慮支援。
10. **行動應用程式拍照建立測驗**——純手機端功能，跟 Playwright 自動化無關，僅記錄以防老師詢問。
