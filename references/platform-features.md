# Wayground 官方功能調查（2026-07）

- 2025-10 由 Quizizz 更名 Wayground；quizizz.com 轉址、帳號資料自動轉移。
- 建立方式：from scratch（18 種題型）、AI 生成（貼主題/內容 + 年級科目偏好）、上傳文件（≤50MB/100 頁，可貼網址/YouTube）、匯入試算表（Excel/Google Sheets 官方模板）、Google Forms。
- 匯入模板欄位：Question Text / Question Type / Option 1–5 / Correct Answer / Time in seconds / Image Link。支援 Multiple Choice、Checkbox、Fill-in-the-Blank、Open-Ended、Poll。純文字，每題最多 1 圖。
- 發布 metadata：名稱、科目、年級、語言、公開性（public/private）、封面。
- 遊戲模式：Live、Homework、Team、Test、Paper、Mastery Peak。指派後產生 join code（`wayground.com/join?gc=…`），學生免帳號可加入。
- 無公開內容創建 API。
