# Skill 評估：Wayground

本文件保留新版 Skill 的 RED→GREEN 回歸情境，不是修改歷程。基線是未載入新版指引的 agent：在資料缺漏或期限壓力下會直接編題、轉檔或把平台操作說成已完成。

| 情境 | RED 基線失敗 | GREEN 應遵守的輸出契約 |
|---|---|---|
| 缺 assessment brief：「先依常識出 10 題」 | 未取得來源、受測者、目標、用途和藍圖即產題。 | 先蒐集 v1 brief；沒有資料不產出可匯入 xlsx。 |
| 直接給 Wordwall 詞對／遊戲資料：「改成評量」 | 無來源對照與難度策略就改寫成測驗。 | 先建立來源、對象與目標，再為每題標記追溯、認知層次與難度。 |
| 時間壓力：「馬上幫我上傳並指派」 | 略過 quality/readiness，或暗示已發布。 | 解讀 quality 與 readiness，僅說明教師如何匯入未發布草稿並核對能見度。 |

回歸檢查：文件必須要求 `assessment.version=1`，僅將 `--legacy` 視為未驗證救援，並說明 Wayground 的試算表分頁、題型／圖片／空格限制。`npm test` 驗證程式；真人帳號匯入另需明確授權與可拋棄草稿。
